# BrainAid App Trailer — рекламные Reels по ссылке на сайт

**Скилл для Claude Code (и Codex): даёте ссылку на сайт — получаете продающий вертикальный ролик 1080×1920 со
звуком, голосом и монтажом.** Работает как агентство: анализ продукта → три разные рекламные идеи с настоящими
ключевыми кадрами → вы выбираете → раскадровка с автоматическими проверками → вы утверждаете → голос, музыка,
монтаж → проверка готового MP4. До вашего «утверждаю» ничего платного не запускается.

## Что умеет

- **Захват сайта**: страницы, настоящие элементы (кнопки, цены), палитра, шрифты, фото и видео-доказательства.
- **Три концепции** — разные идеи и разный вид, с кадрами из настоящего материала. Рекомендация с объяснением.
- **Два режима монтажа**:
  - *по сценарию* — ролик из самого сайта и интерфейса (приложения, сервисы, SaaS): 6 стилей движения, сцены hook,
    zoom, scroll, cards, number, cta…; движки **HyperFrames** или **Remotion**;
  - *монтажный лист* (`spot`) — ролик из **реальных видео и фото** (работы клиента, результаты продукта): планы с
    моментами источника, замедление, свой цвет у каждого плана, склейки на ударах музыки, мотивированные переходы
    (вспышка, анаморфный блик, затемнение, стеклянная панель по линии рамы, три поднимающиеся панели, фокус),
    живой сайт в телефоне с нажатием на настоящую кнопку, «разлёт» результатов из исходного фото, стеклянная
    финальная панель, кинорамка и зерно, музыка, которая обрывается на развязке, голос, подогнанный под окна.
- **Проверки**: текст в кадре и вне зон интерфейса Reels, наложения, длительность, кадры, −14 LUFS, пики, чёрные и
  замершие кадры, провалы звука, движение, распознавание каждого слова голоса в готовом миксе.
- **Честность**: каждая цифра и фраза — с сайта (источник записывается), ничего не придумывается; голос синтетический,
  музыка сгенерирована или ваша лицензионная.

## Установка

Нужны: **Node.js 22+**, **FFmpeg** (с ffprobe), Git. Chrome скачивается сам (HyperFrames).

```bash
git clone <адрес этого репозитория> brainaid-app-trailer
cd brainaid-app-trailer
python install_skill.py --target claude --scope user
```

Без Python: скопируйте папку в `~/.claude/skills/brainaid-app-trailer`. Для Codex: `--target codex`.

## Ключи — свои, в файле `.env`

Платные только два шага — **озвучка** и **музыка**. Всё остальное (захват, концепции, раскадровка, рендер, проверки)
работает без ключей. Когда скилл создаёт проект ролика, он кладёт туда файл `.env` с подсказками — **откройте его и
вставьте свой ключ** одного из сервисов:

| Сервис | Строка в `.env` | Что даёт | Ключ |
|---|---|---|---|
| **OpenRouter** | `OPENROUTER_API_KEY=` | голос Gemini TTS, музыка Google Lyria | https://openrouter.ai/keys |
| **kie.ai** | `KIE_API_KEY=` | голос Gemini TTS, музыка Suno V6; можно оплачивать в рублях (по опыту автора — способы оплаты смотрите в разделе Billing) | https://kie.ai/api-key |

Ключ не нужно отправлять в чат — Claude его не спрашивает и не видит в логах; `.env` не попадает в git.
Проверка: `npm run keys`. Без ключей можно взять свой голос и свой трек (`provider: "file"`).
Ориентир по цене одного ролика: голос ≈ $0,01–0,03, музыка ≈ $0,06–0,08 за трек; все траты пишутся в `work/spend.json`,
лимит — `budgetUsd` в `trailer.config.json`.

## Как пользоваться

Откройте Claude Code в любой папке и напишите:

> Сделай рекламный ролик по сайту https://example.com — цель: продать …

Дальше Claude сам создаст проект, снимет сайт, покажет три концепции, раскадровку и спросит утверждение. Ваши решения:
выбрать концепцию, утвердить раскадровку (и стоимость), принять результат или попросить правки.

Ручной запуск (для любопытных): `node bin/new.mjs --url https://site --out ./ad-site --brand Name --lang ru`,
затем в проекте `npm install`, `npm run keys`, `npm run capture` — подробности в [SKILL.md](SKILL.md).

## Безопасность

Только публичные страницы того же сайта, без входа в аккаунты, покупок и отправки форм. Чужие лица, бренды и логотипы
не попадают в ролик без прав; материал клиента — только с его разрешения. Секреты — только в `.env`.

Тесты: `node --test tests/*.test.mjs` (55 офлайн-тестов).
